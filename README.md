# Netflix Content Analytics Dashboard

## Overview
Analyzed Netflix dataset to understand content trends,
genre popularity, ratings distribution, and country performance.

## Tools Used
Power BI | Data Analysis | Visualization

## Features
- KPI Cards
- Genre Analysis
- Rating Insights
- Release Year Trend
- Country-wise Content Analysis

## Outcome
Interactive dashboard providing business insights
from entertainment data.
